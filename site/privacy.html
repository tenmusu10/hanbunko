プライバシーポリシー

「ふたりごと」（以下「本アプリ」）は、パートナーと2人だけで使うアプリです。本アプリは、相手を見張るための情報を集めないことを大前提に作っています。このポリシーでは、何を保存し、何を保存しないかを説明します。

1. 運営者

本アプリは Cycle games（以下「運営者」）が個人で運営しています。お問い合わせは rokomoko.ten@gmail.com まで。

2. 取得しない情報

本アプリは次の情報を取得しません。

  • 位置情報（GPS、おおよその位置とも）
  • 氏名、メールアドレス、電話番号（登録は不要です）
  • 連絡先、カレンダー、写真ライブラリ全体（あなたが選んだ写真1枚だけを扱います）
  • 既読、オンライン状態、最終ログイン時刻、入力中の状態
  • 広告 ID、利用状況の解析データ（解析ツールや広告の仕組みを組み込んでいません）

3. 保存する情報

情報使い道保存先・形
投稿の中身（かけら・予定・ひとりごとの文や写真）パートナーに届ける（作った日の次の日から表示）Firestore（東京）。端末の中で暗号化してから送る
写真かけらとして届ける端末で小さく圧縮し、位置などの撮影情報を取り除いて暗号化
投稿した日（日付のみ、時刻は持ちません）並べる、保存期間を過ぎたものを消すFirestore。投稿の種類（かけら・予定・苦労カードのどれか）と、どちらの匿名 ID が作ったかも暗号化せずに保存します
匿名の利用者 ID2人をペアとして結びつけるFirebase Authentication（匿名ログイン）
招待コードペアを作るサーバーには置かない。コードに含まれる暗号鍵は2人の端末にだけ残る。ペアの ID とメンバー（2人分の匿名 ID）、ペアを作った日は Firestore に暗号化せずに保存
通知用の端末トークン1日1回のまとめ通知を送る（通知をオンにした場合のみ）Firestore。置けるのは本人だけで、相手を含め誰も読めない
お知らせ済みの投稿の ID同じ投稿を二度お知らせしないFirestore。昨日と今日の分だけを持ち、毎晩置き換える

まとめ通知は、毎晩21時ごろに1回、相手から新しく届いたものがある日だけ送ります。文面は「相手から届いたものがあります」と決まっていて、件数や中身、返事の催促は書きません。送るときは、運営者が GitHub Actions（GitHub の定時実行の仕組み）から Firebase Cloud Messaging に、通知用トークンとこの一文だけを渡します。送るかどうかを決めるために、そのとき匿名 ID と投稿した日（おとといと昨日の分）を読みます。ブラウザで使う場合は、この一文がブラウザの提供元の通知サービスを通って届きます。

投稿の中身を復号する鍵は2人の端末にだけあり、運営者や Google を含む第三者は中身を読めません。そのため、運営者が投稿の内容を確かめたり、復元したりすることはできません。

4. 通信にともない自動で記録される情報

本アプリは Google が提供する Firebase（Authentication、Cloud Firestore、Cloud Messaging）を使っています。通信の際、Google は IP アドレスや端末の種類などを、サービスの運用と安全のために一時的に記録することがあります。運営者はこれを利用者の分析には使いません。詳しくは Firebase のプライバシーとセキュリティ をご覧ください。

5. 第三者への提供

運営者は、法令に基づく場合を除き、利用者の情報を第三者に提供したり売ったりしません。Firebase と、通知を送るときに使う GitHub Actions は、運営者の委託先として情報を扱います（GitHub Actions が扱うのは、通知用トークン、お知らせ済みの投稿の ID、匿名 ID と投稿した日だけで、投稿の中身は扱いません）。データは東京リージョンに保存されますが、Google LLC と GitHub, Inc. は米国の事業者のため、民間事業者の扱いとしては外国の事業者になります。米国には日本の個人情報保護法と同じ内容の包括的な法律はありませんが、両社は個人情報保護のための契約上の措置を講じています。

6. 保存期間（データとアカウントの削除）

もの消えるとき
半分の予定（埋まっても埋まらなくても）作った日から14日後
ひとりごと（見えない苦労）作った日から30日後
かけらの写真作った日から7日後（文は残ります）
自分の投稿すべて自分で削除したとき、すぐ
自分に関する情報すべて退会したとき、すぐ

上の日数を過ぎたものは、その日からどちらの画面にも出なくなります。サーバーから実際に消すのは、作った人の端末です。サーバーでは消す処理を動かしていないため、作った人が次にアプリを開いたときに消えます。しばらく開かない場合は、それまで暗号化されたままサーバーに残ります。

投稿を削除しても、削除したことは相手に知らされません。退会はひとりで、理由を答えずにできます。退会（アプリでは「ペアを解消する」）すると、あなたの投稿、相手の投稿へのあなたの返事（想像の一言、埋めた欄、ありがとう）、匿名 ID、通知用トークンをすぐに消し、ペアから抜けます。相手が書いた投稿は相手のものなので、相手の手元に残ります。バックアップは取っていないため、消したものは元に戻せません。

アプリを削除するだけではサーバー上の暗号化されたデータは残るので、消したい場合は先にアプリ内で退会してください。匿名で使うアプリのため、アプリを削除した後は本人であることを確かめられず、個別にお応えできない場合があります。

7. あなたができること

  • 自分の投稿をいつでも削除する
  • 通知をオフにする（端末の設定からもできます）
  • 退会して、自分に関する情報をすべて消す
  • 保有個人データの開示・訂正・利用停止などを問い合わせ先に求める（ただし中身は暗号化されているため、運営者が開示できるのは保存の有無と日付などに限られます）

8. 安全管理

投稿の中身は端末で暗号化し、通信は TLS で保護します。Firestore のルールで、ペアの2人以外はデータに触れられないようにしています。運営者も、中身を読める管理画面を持ちません。

9. 年齢

18歳未満の方は、保護者の同意を得てからご利用ください。

10. 変更

このポリシーを変えるときは、アプリ内またはこのページでお知らせします。取得する情報を増やす変更は、あらためて同意をいただいてから行います。
