利用規約

この規約は、Cycle games（以下「運営者」）が提供する「はんぶんこ」（以下「本アプリ」）の使い方の約束です。本アプリを使うことで、この規約に同意したものとします。

第1条（本アプリの考え方）

本アプリは、2人が半分ずつ持ち寄って楽しむためのものです。相手を監視したり、行動を強いたりするために使わないでください。2人は常に対等で、どちらかが相手の設定を変えたり、相手の投稿を消したりすることはできません。

第2条（利用の始め方）

  1. 匿名で始められ、氏名やメールアドレスの登録はいりません。
  2. 招待コードを2人でやり取りしてペアになります。ペアは2人だけで、3人以上は加われません。
  3. 18歳未満の方は保護者の同意を得てください。

第3条（料金）

本アプリは無料です。将来有料の機能を設ける場合は、あらかじめ内容と料金をお知らせします。有料の機能によって2人の間に権限の差を作ることはしません。

第4条（投稿）

  1. 投稿の権利は投稿した人にあります。運営者は中身を読めず、広告や学習などに使うこともありません。
  2. 自分の投稿はいつでも削除でき、削除したことは相手に知らされません。
  3. 相手がすでに見た投稿を、相手が画面撮影などで残すことは、本アプリでは防げません。
  4. 保存期間を過ぎた投稿は、プライバシーポリシーに書いたとおり自動で消えます。

第5条（禁止すること）

次のことはしないでください。

  • 相手の同意なくペアを作ること、相手の端末を勝手に操作すること
  • 本アプリを使って相手を脅したり、負担を強いたり、嫌がらせをしたりすること
  • 相手の投稿を、相手の同意なく第三者に見せたり公開したりすること
  • 法令に反する写真や文を送ること、他人の権利を侵すこと
  • 本アプリやサーバーに不正にアクセスしたり、過度な負荷をかけたりすること

これらに当たると運営者が判断した場合は、その利用者の利用を止めることがあります。ただし運営者は中身を読めないため、判断は不正アクセスの記録や、利用者からの申し出にもとづきます。

第6条（休憩・退会）

  1. 休憩と退会は、それぞれがひとりで、理由を答えずにすぐ行えます。相手の承認はいりません。
  2. 退会すると、その人の投稿と情報はすぐに消え、ペアは解除されます。消えたものは元に戻せません。
  3. 相手が退会した場合、あなた自身の投稿はあなたの手元に残り、相手がそれに付けた返事は消えます。
  4. 端末をなくしたり、初期化したり、アプリを削除したり、機種変更したりすると、匿名の利用者 ID と暗号鍵が失われ、それまでの投稿は読めなくなります。

第7条（提供の変更・終了）

運営者は個人で運営しているため、内容を変えたり、提供を終えたりすることがあります。終了する場合は、少なくとも30日前にアプリ内でお知らせし、終了後にサーバー上のデータをすべて消します。

第8条（保証と責任）

  1. 本アプリはあえて不完全に作っています。置いた予定が埋まらずに消える、届くのが遅れるなどのことが起き得ます。大事な約束や記録は別の方法でも残してください。
  2. 運営者は、本アプリが止まらないことや、データが失われないことを保証しません。
  3. 運営者の故意または重大な過失による場合を除き、本アプリの利用で生じた損害について運営者は責任を負いません。消費者契約法などの法令でこの定めが無効になる場合は、その法令に従います。
  4. ペアの2人の間で起きたことは、2人の間で解決してください。

第9条（規約の変更）

この規約を変えるときは、変更の内容と日付を、施行の前にアプリ内またはこのページでお知らせします（民法第548条の4）。

第10条（準拠法と裁判所）

この規約は日本の法律に従います。本アプリに関する紛争は、運営者の住所地を管轄する地方裁判所を第一審の専属的合意管轄裁判所とします。
